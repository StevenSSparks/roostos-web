What it does

A real AI conversation, in your pocket

Everything runs on the device over your own WiFi. No phone, no companion app.

💬

On-screen chat

Type on the QWERTY, press Enter, read the reply on the color LCD. Scrollback, adjustable fonts, your-message-stays-on-top.

🔀

Four AI providers

Anthropic, OpenAI, Gemini, or a local Ollama box. Pick the active one in Settings — it verifies the key answers before switching.

⚙️

BlackBerry-style Settings

A tidy menu of sub-pages — Display, Colors, AI Provider, System — all persisted across reboots.

🐤

Branded boot splash

The RoostOS chick-on-an-antenna on every boot.

🎨

Yours to theme

Message + input fonts and colors are configurable and saved.

🛠️

Hackable

PlatformIO, open source. GPS, maps, LoRa, games and an on-device tool loop are on the roadmap.

Get set up

Clone → configure → flash → fun

You need a LILYGO T-Deck Plus, a USB-C cable, and an API key for at least one provider.

STEP 1

Get a key

Anthropic: console.anthropic.com → API Keys. (Or OpenAI / Gemini / a local Ollama host.)

STEP 2

Build your secrets

Use the config builder to generate secrets.h — or copy secrets.example.h and edit by hand.

STEP 3

Clone + drop it in

Clone the repo, put your file at include/secrets.h (it's git-ignored).

STEP 4

Flash

pio run -e app -t upload. Type a message + Enter. Trackball click opens Settings.

# 1. clone
git clone https://github.com/StevenSSparks/roost-tdeck.git
cd roost-tdeck

# 2. configure (or use the web builder at roostos.dev/tdeck/config)
cp include/secrets.example.h include/secrets.h
$EDITOR include/secrets.h        # fill in WiFi + at least one API key

# 3. flash it (T-Deck on USB-C)
pio run -e app -t upload
